# Kenney assets

Artwork by **[Kenney](https://kenney.nl/)**, released under **[CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/)**.

These references demonstrate compact silhouettes, clear color clusters, modular environments, and small UI components.

[sources.json](sources.json) lists each tile's original filename, collection, and license. Individual reference tiles retain their original pixels; the contact sheets arrange them with labels for browsing.

## Use in the examples

- **Potion variants:** the original frame is Tiny Dungeon tile 0113. Azure and violet replace its two gray fill colors while preserving the shape, boundary, and stopper.
- **Tile scene:** an arrangement of Tiny Town ground, roof, wall, doorway, and tree tiles.
- **UI components:** the four selected UI Pack tiles arranged as a labeled sheet.
- **Image editing:** Tiny Dungeon tile 0113 is placed on a flat background, recolored and outlined.

The underlying artwork is CC0. The separately authored character templates, UI skins/icons, bitmap alphabet, terrain textures/blocks, sword, beacon, documentation and scripts are MIT.
