# 参考图与生成

文字生成、照片转像素、风格匹配和语义编辑，使用助手自带的图像工具，或在原生网格上仔细重绘完成；随后由本地工具整理成干净、可编辑的素材。PixelLab 只是可选扩展，从不是必需的。

## 根据参考图制作

> 这是我游戏的截图。用 pixel-art-studio 画三个新敌人，配色、描边和比例与截图保持一致。

助手会从参考图中读取网格尺寸、剪影、视角、配色、描边、光照和细节密度，再按此绘制。生成或手绘的图片一定会在目标网格上重绘：轮廓、像素尺寸、色块和透明度都会重新整理，绝不会把放大或模糊过的图片当作像素画交付。

## 不同需求的处理方式

| 需求 | 默认方式 |
|---|---|
| 文字生成像素画、概念或风格参考 | 助手的图像工具，然后在网格上细化；或直接手写网格 |
| 照片或图片转像素画 | 在目标网格上重绘；用 `image_ops.py` 处理调色板与尺寸 |
| 角色多方向视图 | `character.py` 模板，或根据参考图逐个方向重绘 |
| 换装与配色变体 | 角色部件与配色角色，或 `image_ops.py` 换色和补图 |
| 动作与中间帧 | 绘制关键姿态，用 `animate.py` 组装 |
| 局部重绘与修补 | 绘制补丁，再用蒙版合成 |
| 瓦片、地图、等距地块 | `world.py`，自定义美术作为物件摆放 |
| 界面 | `ui.py` |

## 可选：PixelLab

[PixelLab](https://www.pixellab.ai) 是第三方像素画生成服务，需要单独的账号并消耗付费额度。只有同时满足以下三点时，Skill 才会使用它：

1. 你主动要求使用 PixelLab，或在助手提出时同意。
2. 助手中已经接入了 PixelLab 连接器，或已经设置了 `PIXELLAB_API_KEY`。
3. 你确认了即将发起的生成调用，因为每次调用都会消耗你的额度。

否则助手会按上面的默认方式继续，也不会向你索要令牌。如需使用附带的客户端：

```bash
python -m pip install -r requirements-pixellab.txt
python scripts/pixellab.py list
```

`list` 和 `schema` 只读取实时工具目录；`call` 才会生成。返回的图片会保存到本地，并像其他生成图一样在网格上细化。详见 [production-workflows.md]({{repo}}/blob/main/skills/pixel-art-studio/references/production-workflows.md)。
